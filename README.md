Description
A multi-page dashboard application built with React Router to demonstrate client-side navigation, dynamic routes, and reusable component architecture.
 
Live Demo
🔗 Live: https://mohammad-aahil.github.io/dashboard-app

Source Code
💻 GitHub: https://github.com/Mohammad-Aahil/dashboard-app

Features
* Multi-page navigation
* Dynamic routing
* URL parameter handling using useParams
* Reusable React components
* Organized project structure
* Responsive layout

Technologies Used
* React.js
* React Router
* JavaScript (ES6+)
* CSS
* Vite
